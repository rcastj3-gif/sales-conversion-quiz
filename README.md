- Niche: sales_conversion

## Files
- quiz.html: **Complete quiz ready to deploy** ⭐
- quiz.json: Quiz configuration
- sequences.json: Email sequences
- automations.json: Automation rules

## Quick Start
1. Open quiz.html in browser to test
2. Run with --deploy to setup GlobalControl
3. Deploy quiz.html to Vercel/Netlify
4. Start capturing leads!

## Deployment
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
cd sales_conversion-quiz
vercel --prod
```
